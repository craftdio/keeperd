터미널에서 GitHub에 로그인하세요

KeepERD 서버를 실행한 컴퓨터의 터미널에서 아래 명령을 실행하세요. 브라우저의 GitHub 로그인과는 별개입니다. 

gh auth login --hostname github.com --git-protocol https --web
gh auth setup-git
gh auth status

레포에 접근 가능한 계정으로 로그인한 뒤, 아래 로그인 다시 확인을 누르세요. 서버를 재시작할 필요는 없습니다.

다른 로컬 저장소 또는 worktree 추가

.git이 바로 들어 있는 폴더만 등록합니다. 연결된 worktree도 지원합니다.

Git clone 또는 Codex worktree의 루트 경로를 입력하세요. 경로는 이 컴퓨터의 개인 설정에만 저장됩니다.

배치·색상·메모는 이 브라우저에서 같은 레포의 브랜치끼리 공유됩니다.
중요한 배치는 ChartDB의 JSON 내보내기로 백업하세요.
db/schema/*.sql을 우선 사용하고, 없으면 db/migration/*.sql을 재생합니다.
로컬 브랜치는 커밋된 스키마만 반영합니다.

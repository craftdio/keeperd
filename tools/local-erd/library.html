저장된 ERD 관리

← Sync 화면

Sync로 만든 스키마 파일과 현재 브라우저에서 편집한 ERD 작업 데이터를 관리하세요. GitHub 로그인 없이 볼 수 있습니다.

KeepERD는 ChartDB 기반의 독립적인 비공식 포크이며, ChartDB와 제휴하거나 보증을 받지 않습니다.

저장 공간 확인 중…

Sync 결과 스키마 파일 Sync할 때 읽어온 테이블·컬럼·관계 정보입니다. 삭제해도 같은 레포와 브랜치를 다시 Sync하면 생성됩니다.
이 브라우저의 ERD 작업 데이터 직접 수정한 테이블 배치·색상·영역·메모·필터입니다. 삭제하면 다시 Sync해도 복구되지 않습니다.

저장된 ERD를 불러오는 중…

브라우저 작업 데이터 용량은 JSON 크기 추정치이며 실제 디스크 점유량과 다를 수 있습니다.
선택 삭제는 위 두 종류의 데이터와 자동 백업을 지웁니다. 다른 브라우저의 데이터는 지우지 않습니다.
직접 GitHub에서 내려받아 작업 중인 프로젝트 폴더와, ChartDB가 다음 Sync를 위해 내부에 보관한 코드 복사본도 삭제하지 않습니다.
카드의 이 브랜치에서 마지막으로 Sync한 스키마 JSON은 작업 배치 백업이나 레포 공통 작업 데이터 가져오기용 파일이 아닙니다.

선택한 ERD를 삭제할까요?

Sync 결과 스키마 파일과 이 브라우저의 배치·색상·영역·메모·필터·자동 백업을 삭제합니다.

브라우저 작업 데이터는 다시 Sync해도 복구되지 않습니다. 중요한 작업은 먼저 ChartDB JSON으로 내보내세요.

직접 받은 프로젝트 폴더와 ChartDB가 Sync용으로 보관한 코드 복사본은 삭제하지 않습니다.

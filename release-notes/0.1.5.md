## New features

- Share the layout of selected tables as JSON. Choose tables by schema, search, or directly on the canvas; review selected-table chips and remove a table by clicking it again.
- Import selected-table layouts into another ERD from the same repository. Preview matching and skipped tables before applying, and undo the affected placements from a recovery backup. Columns, relationships, Areas, notes, and unselected placements are preserved.

## Fixes and improvements

- Reduce unnecessary sidebar and table-menu rendering while panning or zooming. Table, Area, and note creation continues to use the current viewport.
- Fetch only the requested workspace data and return small revision acknowledgements after saving. Existing full-layout JSON files, browser migration, and stale-save protection remain supported.
- Move local branch detail queries off the HTTP event loop, share simultaneous requests, and reuse repeated Git graph calculations. Refreshes still read current refs and uncommitted schema changes.
- Remove the automatic GitHub star-request popup.
- Disable inherited Git/SSH GUI askpass when KeepERD uses GitHub CLI credentials. Failed authentication returns an error instead of falling back to an inherited interactive helper.
- Extend extracted-release checks for selected-table sharing, scoped reads, revision conflicts, browser modules, and branch-query workers without `node_modules`.

## Upgrade

After the 0.1.5 release and matching Homebrew formula have been published:

```sh
keeperd stop
brew update
brew upgrade craftdio/keeperd/keeperd
keeperd --version
keeperd start
```

The version command should print `KeepERD 0.1.5`. Existing SQLite workspaces and JSON layout files remain supported; no new schema Sync or SQLite schema migration is required. The private Node runtime remains **26.12.1**.

KeepERD continues to store work locally. Layout sharing uses manual JSON files and does not upload data automatically. Browsers using the same server share a workspace with revision-conflict protection; this release does not add real-time collaborative editing. M1/8GB, long-running, and multi-user performance targets have not been established.
